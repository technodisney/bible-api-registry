## Bible API providers

| Provider | Sign up | Free access | Paid access |
|---|---|---|---|
| [API.Bible](https://api.bible/) | [Account, app approval, and API key](https://api.bible/sign-up/starter) | Starter: $0; open-access Bibles plus up to 3 selected copyrighted Bibles; non-commercial | Pro from US$29/month; commercial per-translation licences publicly start around US$10/month |
| [ESV API](https://api.esv.org/) | [Free account and API key](https://api.esv.org/) | Free for qualifying non-commercial use | No public API price; contact Crossway for expanded commercial licensing |
| [NLT API](https://api.nlt.to/) | [API key](https://api.nlt.to/) | Non-commercial access | No public self-service commercial price |
| [NET Bible API](https://labs.bible.org/api_web_service) | [None](https://labs.bible.org/api_web_service) | Free passage API | No published tier; commercial rights require permission |
| [Bible Brain](https://www.faithcomesbyhearing.com/bible-brain/developer-documentation) | [API-key application with intended-use details](https://4.dbt.io/api_key/request) | Free for qualifying non-commercial access | No public price; contact FCBH |
| [Digital Bible Library](https://library.bible/) | [Free account; organisation workflow for controlled content](https://app.library.bible/signup) | Open-access/public-domain/Creative Commons content | No public standard price; rights-holder agreements vary |
| [Bible Gateway API](https://www.biblegateway.com/api/documentation) | [No public self-service process documented](https://www.biblegateway.com/api/documentation) | No public developer tier advertised | No public pricing |
| [Free Use Bible API](https://bible.helloao.org/) | [None](https://bible.helloao.org/) | No key or stated usage limits | None advertised |
| [DailyBible API](https://dailybible.ca/api-docs) | [None](https://dailybible.ca/api-docs) | Free public-domain catalogue | None advertised |
